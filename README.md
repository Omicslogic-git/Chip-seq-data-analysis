# GSE68952 H3K4me3 ChIP-seq Pipeline
### Huntington Disease vs Control · Human PFC Neurons · hg38

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Platform](https://img.shields.io/badge/Platform-Linux-blue.svg)](https://www.linux.org/)

[![Genome](https://img.shields.io/badge/Genome-hg38%20GRCh38-orange.svg)](https://www.ncbi.nlm.nih.gov/assembly/GCF_000001405.26/)

A fully reproducible 10-stage ChIP-seq analysis pipeline for the re-analysis of
[GSE68952](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE68952) —
H3K4me3 ChIP-seq in Huntington Disease (HD) vs neurologically normal control
human post-mortem prefrontal cortex neurons.

**Reference paper:** Dong, Tsuji et al. *PLOS ONE* 2015.
[doi:10.1371/journal.pone.0144398](https://doi.org/10.1371/journal.pone.0144398)

## Pipeline Summary

```
Stage 1   Download         SRA Toolkit (prefetch + fasterq-dump)
Stage 2   QC               FastQC + MultiQC
Stage 3   Trimming         Trim Galore (Cutadapt backend)
Stage 4   Alignment        Bowtie2 (hg38 noalt) → samtools → Picard
Stage 5   Post-align QC    deepTools (fingerprint, PCA, correlation, bigWig)
Stage 6   Peak calling     MACS3 --broad → consensus peak set
Stage 7   Diff. binding    DiffBind + DESeq2                       [R]
Stage 8   Annotation       ChIPseeker + clusterProfiler GO/KEGG    [R]
Stage 9   Motif analysis   Homer findMotifsGenome.pl
Stage 10  Visualisation    deepTools heatmaps + R summary figures
```

## Requirements

### System Requirements

- Linux (Ubuntu 20.04+ recommended)

- ≥ 150 GB free disk space

### Software

All tools are managed via a single conda/mamba environment.

**Bash stages (1–6, 9–10):** `chipseq_analysis` conda environment

| Tool | Version | Purpose |
|---|---|---|

## Quick Start

### 1. Clone the repository

```bash
git clone https://github.com/your-org/GSE68952-chipseq.git
cd GSE68952-chipseq
```

### 2. Set up environments

```bash
# Install mamba if not already available
conda install -n base -c conda-forge mamba -y

# Create the main analysis environment (~4-6 GB, takes 10-20 min)
bash setup_chipseq_env.sh

# Create the R/Bioconductor environment for DiffBind
mamba create -n diffbind_env -c conda-forge -c bioconda \
    r-base=4.3 bioconductor-diffbind bioconductor-deseq2 \
    bioconductor-chipseeker bioconductor-txdb.hsapiens.ucsc.hg38.knowngene \
    bioconductor-org.hs.eg.db bioconductor-clusterprofiler \
    r-ggplot2 r-pheatmap r-rcolorbrewer r-dplyr r-enrichplot -y

# Load Homer hg38 genome (~3 GB, one-time)
conda activate chipseq_analysis
perl $(find $CONDA_PREFIX -name "configureHomer.pl" 2>/dev/null | head -1) -install hg38
```

### 3. Run the pipeline

```bash
conda activate chipseq_analysis

# Bash stages (run in order)
chmod +x stage*.sh
./stage1_download.sh  2>&1 | tee run_stage1.log
./stage2_qc.sh        2>&1 | tee run_stage2.log
./stage3_trim.sh      2>&1 | tee run_stage3.log
./stage4_align.sh     2>&1 | tee run_stage4.log
./stage5_postqc.sh    2>&1 | tee run_stage5.log
./stage6_peakcalling.sh 2>&1 | tee run_stage6.log

# R stages
conda activate diffbind_env
Rscript stage7_diffbind.R   2>&1 | tee run_stage7.log
Rscript stage8_annotation.R 2>&1 | tee run_stage8.log
Rscript stage8b_strict.R    2>&1 | tee run_stage8b.log   # optional strict FC analysis

# Homer motif analysis
conda activate chipseq_analysis
./stage9_homer.sh 2>&1 | tee run_stage9.log

# Final visualisation
./stage10_visualisation.sh 2>&1 | tee run_stage10.log

# Overlaid TSS profile
conda activate diffbind_env
Rscript plot_TSS_overlay.R
```

## Stage-by-Stage Guide

### Stage 1: Download

Downloads 13 FASTQ files from NCBI SRA and three reference resources.

```bash
conda activate chipseq_analysis
./stage1_download.sh 2>&1 | tee run_stage1.log
```

**Outputs:**
- `01_raw_fastq/SRR202828{78..90}.fastq.gz` — 13 compressed FASTQ files
- `genome/GRCh38_noalt_as/` — Bowtie2 hg38 index (no ALT contigs)
- `genome/hg38-blacklist.v2.bed` — ENCODE blacklist v2
- `genome/hg38.chrom.sizes` — chromosome sizes for deepTools
- `samplesheet.csv` — sample metadata used by all downstream stages

**Resume-safe:** re-running skips already-downloaded files.

---

### Stage 2: Quality Control

Runs FastQC on all 13 samples (parallel with GNU parallel if available) and aggregates into a single MultiQC HTML report.

```bash
./stage2_qc.sh 2>&1 | tee run_stage2.log
```

**Key QC findings:**
- All 13 samples pass per-base quality and adapter content
- Three samples flagged for low read count: C4 (2.84M), HD2 (3.18M), HD4 (2.72M)
- Duplication flagged by FastQC — **expected and normal** for ChIP-seq

---

### Stage 3: Adapter Trimming

```bash
./stage3_trim.sh 2>&1 | tee run_stage3.log
```

**Parameters:** `--quality 20 --length 20`

**Result:** 0.00% quality trimming across all samples — data was already clean.
26–40% "adapter detected" is normal for 36 nt SE reads (Illumina read-through).

---

### Stage 4: Alignment

```bash
./stage4_align.sh 2>&1 | tee run_stage4.log
```

**Pipeline per sample:**
1. `bowtie2 --very-sensitive` → coordinate-sorted BAM
2. `samtools view -F 4 -q 30` → MAPQ≥30 filter
3. `bedtools intersect -v -b blacklist.bed` → blacklist removal
4. `picard MarkDuplicates` → mark (not remove) duplicates
5. `samtools flagstat` → alignment statistics

**Result:** 100% mapping rate across all 13 samples.

> **Note on optical duplicate distance:** Set to `100` for Genome Analyzer II
> (non-patterned flowcell). Use `2500` for NovaSeq/NextSeq.

---

### Stage 5: Post-Alignment QC

```bash
./stage5_postqc.sh 2>&1 | tee run_stage5.log
```

**Outputs:**
- `plotFingerprint` — confirms J-curve enrichment in all ChIP samples
- `bamCoverage` → RPGC-normalised bigWig tracks (load in IGV)
- `bamCompare` → log2(ChIP/Input) bigWig tracks
- `multiBamSummary` + `plotCorrelation` → Pearson r heatmap
- `plotPCA` — HD vs Control separation on PC2

---

### Stage 6: Peak Calling

```bash
./stage6_peakcalling.sh 2>&1 | tee run_stage6.log
```

**MACS3 parameters:** `--broad --nomodel --extsize 200 --keep-dup auto`

**Consensus peak set:** 33,073 merged → 33,063 after blacklist → **25,217 after ≥2 sample filter**

---

### Stage 7: Differential Binding

```bash
conda activate diffbind_env
Rscript stage7_diffbind.R 2>&1 | tee run_stage7.log
```

**Checkpoint:** saves `07_diffbind/GSE68952_dba_counted.rds` after read counting.
If the script fails after counting, it will not recount on re-run.

**Key outputs:**
- `GSE68952_diffbind_results.csv` — significant differential peaks
- `GSE68952_diffbind_loss.bed` — peaks lost in HD (used in Stage 10)
- `GSE68952_diffbind_gain.bed` — peaks gained in HD
- `plots/04_volcano_plot.png` — publication-ready volcano

---

### Stage 8: Annotation and Pathway Analysis

```bash
Rscript stage8_annotation.R  2>&1 | tee run_stage8.log   # loose FC=0.585
Rscript stage8b_strict.R     2>&1 | tee run_stage8b.log  # strict FC=1.0
```

**Two-tier analysis:**
- **Loose (FC ≥ 0.585):** 1,230 genes → broad GO terms (use for overview)
- **Strict (FC ≥ 1.0):** 206 genes → 8 KEGG pathways (higher confidence)

**Homer BED files prepared** in `09_homer/` for Stage 9.

---

### Stage 9: Motif Analysis

```bash
conda activate chipseq_analysis
./stage9_homer.sh 2>&1 | tee run_stage9.log
```

**Primary analysis:** `all_differential_v2` — all 8,202 FDR<0.05 peaks (sufficient power for 400+ known motifs).

> **Note:** The `loss_promoter` subset (~180 peaks after TSS + FC filtering) is
> underpowered — Homer only tests ~16 motifs. Always use `all_differential_v2`
> as the primary result.

**View results:**
```bash
firefox 09_homer/results/all_differential_v2/knownResults.html
```

---

### Stage 10: Visualisation

```bash
conda activate chipseq_analysis
./stage10_visualisation.sh 2>&1 | tee run_stage10.log

conda activate diffbind_env
Rscript plot_TSS_overlay.R       # overlaid HD vs Control TSS profile
```

**Open IGV session:**
```bash
igv -g hg38 10_visualisation/igv_tracks/GSE68952_IGV_session.xml
# Navigate to DRD2: chr11:113,409,000-113,445,000
```

> **Important — TSS profile directionality:** The overlaid TSS profile
> (`plot_TSS_overlay.R`) uses `GSE68952_diffbind_loss.bed` as the regions file.
> Using all consensus peaks mixes lost and gained peaks, producing misleading
> directionality where HD appears higher. Stage 10 Step 5b generates the
> correct `loss_peaks_profile_data.tab` automatically.

## Known Issues and Fixes

| Issue | Cause | Fix |
|---|---|---|
| Script exits silently after first sample | `set -e` + `((N++))` returns exit 1 when N=0 | Use `N=$((N + 1))` throughout |
| `MACS2 ImportError: __log_finite` | glibc ≥ 2.31 removed this symbol from Cython | Use MACS3 (`sed -i 's/macs2/macs3/g' stage6_peakcalling.sh`) |
| `plotProfile: unrecognized arguments --xAxisLabel` | deepTools 3.5.x does not support `--xAxisLabel` in `plotProfile` | Remove `--xAxisLabel` and `--yAxisLabel` flags |
| `deeptools plotFingerprint` not found | deepTools tools are standalone binaries, not subcommands | Call `plotFingerprint` directly, not `deeptools plotFingerprint` |
| `dba.count error: unused argument (removeDup)` | DiffBind API change | Use `bRemoveDuplicates = TRUE` |
| `DiffBind: dba.plotPCA main= error` | `main=` argument conflicts with trellis internal call | Remove `main=` from `dba.plotPCA()` calls |
| Homer tests only 16 motifs | Peak set too small (<200 peaks) | Use `all_differential.bed` (8,202 peaks) not `loss_promoter.bed` |
| `picard --version` kills script under `set -e` | Picard exits code 1 for `--version` | Use `|| VER="installed"` fallback in version checks |
| `libxml2 not found` during R package install | Missing system library | `sudo apt-get install -y libxml2-dev libcurl4-openssl-dev` |

## Differences from Original Paper

| Aspect | Original Paper (2015) | This Pipeline |
|---|---|---|
| Genome build | hg19 | **hg38 (GRCh38)** |
| Peak caller | MACS2 | **MACS3** (MACS2 incompatible with Python 3.10+) |
| Differential peaks | ~2,830 | **8,203** (different FC cutoff + genome build) |
| Direction | ~55% down in HD | **1,629 lost vs 602 gained** at \|FC\|≥0.585 |
| Blacklist | Not specified | **ENCODE hg38 blacklist v2** |
| Annotation DB | hg19 TxDb | **TxDb.Hsapiens.UCSC.hg38.knownGene** |
| Key validated gene | DRD2 (reduced H3K4me3) | **DRD2 confirmed** ✓ |
